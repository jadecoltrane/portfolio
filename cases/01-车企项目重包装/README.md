# 案例① 车企真实项目重包装

**定位**:证明"我做过真车、懂座舱业务",并用 LLM 延伸段展示向 AI 交互迁移的思考。不求惊艳,求扎实可信。

## 框架(发现问题 → 分析 → 方案 → 结果)

### 1. 背景与我的角色
- 项目是什么、我负责哪些模块(待补:第 2/3 段工作具体经手的功能模块)
- ⚠️ 外包身份不回避但也不主动强调,话术写"作为 UX 设计师深度参与 XX 模块"

### 2. 发现问题
- 从需求方给的"增删查改"里往回挖:这个需求背后的用户问题是什么?
- 有没有数据/用户反馈/竞品对比可以引用(脱敏)

### 3. 分析与方案
- 设计决策点 2-3 个,每个讲清楚"为什么这么做、还考虑过什么、为什么放弃"
- 车规约束(驾驶分心、可达性、亮暗态)是加分叙事,专门写一小节

### 4. 结果
- 上线了什么、有没有可引用的指标;没有硬指标就写验收/评审结论

### 5. ✨ LLM 延伸(本案例的差异化尾巴)
- "如果今天重做这个模块,引入 LLM 我会怎么设计"
- 1-2 页概念稿即可,和案例②呼应但不重复
