# 提示词还能不能再精简

2026-10-26。先说结论,再说怎么改。

---

## 先说一件事:清单十条你全上了

对了一遍,昨晚那份清单在新提示词里一条不落:

| 清单 | 新提示词里的对应 |
|---|---|
| 1 第 3 级提示唯一锁定目标 | level 2 → `one function description that singles out the target and nothing else natural` |
| 2 说得对但不是目标判模糊 | `natural English that does the task with another expression = fuzzy, never miss` |
| 3 第 2 级换成「换个说法」 | level 1 → `换个说法`,还加了「先写 answer 再倒推大白话」 |
| 4 喂给产出的一律英文 | `use cards: prompt and hint in English only` |
| 5 已掌握加长间隔复习 | `a long-review card for every 已掌握 row with 掌握日期 60+ days ago` |
| 6 N 降到 3 | `N = 3` |
| 7 降低开口门槛 | 语音和 talk 合并成一个「开口练」步骤 |

| 9 90 秒自己想内容 | `lesson.talk` |

**第 10 条你做得比我建议的好。**我只说「每周记一次卡壳几次」,你做成了页面直接记 `stalls`

## 结论:能精简,但省下来的不是钱,是注意力

**先把一个误区去掉。**把语音模板、轮换清单搬进 `story/state`,**并不省 token**——
state 每天都要读,搬过去只是换了个地方进上下文。真要省字数,只能靠去重和改写。

**那为什么还值得精简?**因为这份提示词已经长到「后面的规则容易被漏掉」。
提示词一天只跑一次,token 成本可以忽略;**失败成本是一整天的练习作废**。
所以精简的目标是**让每条规则都被执行到**,不是让它变短。

按这个标准,分三类。

---

## 一、真能删的(去重 + 改写,粗估 10–15%)

1. **「never mention transcripts」说了两遍**——OUTPUT 一次,LISTENING 一次。留一处。
2. **英语-only 的规则说了三遍**——LANGUAGE 一次、`use cards: prompt and hint in English only`
   一次、`use hints` 一次。LANGUAGE 那条已经覆盖,后两处可以合成一句。
3. **WHO 那段和 `story/state.jade` 重复**。state 里已经有她的真实情况,
   WHO 可以压成两行:目标 + 「中文先行,语序会缠」这个病灶 + 指向 state。
4. **`规律 ①–⑩` 的全文**——这十条本来就在表达库的「英语思维规律」表里(提示词自己写了
   `Don't edit the 英语思维规律 table`)。而第 3 步本来就要读那份文档。
   可以改成:`批改 note 按表达库「英语思维规律」表的编号标注`。
5. **介词核心画面那一串**(in/on/at/into/as/with/for/to/by)只在批改里用,
   可以挪进 `teacherNotes`,提示词里留一句「介词按 teacherNotes 的核心画面讲」。

---

## 二、该搬家的(不省 token,但让轮换从「靠记性」变成「可检查」)

这三处搬进 `story/state`,好处不是短,是**正确**:

1. **语音 prompt 的三段 verbatim**(粗估 170 词,每天原样重复一遍)。
   搬成 `state.voiceBoiler`,提示词里写「三段固定文字照抄 state.voiceBoiler」。
2. **小练习的 focus 轮换表**(11 项)。搬成 `state.focusPool` + `state.lastFocus`。
   **现在是靠模型记得昨天用了哪个,这根本不可靠**;变成数据之后轮换才真的成立。
3. **周末话题表**(14 项)。同理,配一个 `state.usedTopics`,
   「最近 7 天没用过」就从猜变成了查。

---

## 三、千万别动的

这几块是这一周一条一条调出来的,每一条背后都有一次真实的失败。**压缩它们等于把债还回去:**

- 四级卡片的格式规定(level 0/1/2/3 各自给什么、不给什么)
- `never the chunk or its key words in a prompt or hint` —— 10/18 的教训
- `no spelling hints, no stage match/cue` —— 决策 08 和 match 覆盖判定那个坑
- 判定那条 `another expression = fuzzy, never miss` —— k11
- STEP 0 的表达库分支表(got / fuzzy / miss / no result / long review 各怎么处理)
  —— 「没做算没复习」就在这里面
- `a NEW situation that is clear on its own (no events she doesn't know about)`
  —— 搬家那张和阿拉伯语那张

这些看着啰嗦,但每一句都在防一个已经发生过的具体错误。

## 还有一个结构建议(可选)

现在规则是按「页面的步骤」分块的(复习卡 / 批改 / 小练习 / 故事 / 听力 / 开口练)。
有几条规则横跨所有步骤——英语-only、不许出现目标表达、不许编造——
它们现在散在各块里,所以才会重复。

可以抽一个「**铁律**」小节放最前面,五六条,全局生效;各步骤里就不用再重申了。
这比任何删减都更能解决「后面的规则被漏掉」。
