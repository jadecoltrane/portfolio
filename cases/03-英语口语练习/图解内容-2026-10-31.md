# 英语练习：新增流程和判分图解的文字内容

> 内容同步于 2026-10-31，对应 u6、u7、u8 三组补图；图片本身不入库。**真实网页产品截图**依然以案例原有素材为准；新增生成 UI 是帮助理解的概念示意，不能冒充已上线功能。

## u6｜一天的练习流程

**建议图题**：从当天任务到练习、反馈与后续复习。

**实际目标**：每天以有限时间完成练习；将练习中的薄弱表达用于后续题目与间隔复习。个人产品由本人定义学习流程、文案、判分及生成规则；AI 帮助完成开发与每日内容生成。

**演示步骤**：查看当天任务 → 读题或准备回答 → 需要开口时借助外部语音工具 → 返回网页记录或查看相关表达 → 按复习安排继续练习。中间的“聊天窗口／内置录音按钮”是概念图，**不代表原网页实现了实时语音会话、内置麦克风录音或自动语音转写**。

**可用图注**：展示一天练习的任务组织方式；实际语音练习需要借助外部工具，图片中的对话和反馈界面为示例重绘。

## u7｜网页端与外部语音工具的职责分工

**建议图题**：网页管理练习和复习；开口环节在外部工具完成。

- **网页**：任务选择、题目与提示、文字层面的练习或复习、记录与复习规则。
- **外部工具**：辅助完成实际开口对话。它不是本网页内嵌的模块。
- **交接**：使用者完成外部练习后回到网页继续流程。**图中的自动回传、结果自动入库、语音评分和数据实时同步均未核实实现**，不能当作实际系统能力。

**可用图注**：跨工具流程说明，不表示网页与语音工具具备正式 API 连接或自动同步能力。

## u8｜判分方式从本人自评到机器／AI 参与判断

**建议图题**：为什么调整判分依据，而不是直接对比两个阶段的正确率。

**真实的设计演变**：早期依赖本人自评，容易随当天主观判断变化；后期改为更明确的自动或 AI 判定，并区分记不起目标表达、表达自然但没使用目标词等不同情形。项目目标是改善判分口径与错误定位，不是证明英语能力突然提升。

**比较维度**：判定发起者、评分依据、错误分类、结果能否回看，以及需要怎样验证新规则是否生效。

**真实数据的边界**：已有 5 天自评阶段的 81% 和另一 5 天机器／AI 阶段的 58% 描述性数据，但题量、题型和判定规则变化，二者**不能直接用来推断学习进步或退步**。单用户样本也不能推断一般用户效果。

**虚构数字处理**：生成 UI 中的 78/100、四个细项得分、示例反馈和“更稳定”的效果暗示均未被真实数据证实，只能作为**样例控件**；不得写成真实模型输出或验证结论。

## 仍缺少的用户体验证据

真实的产品流程已具备一名使用者的持续记录，但尚无多人可用性测试、独立用户招募或语音模块端到端自动化验证。现阶段展示重点应放在**个人使用问题 → 设计取舍 → 真实界面 → 可核查的规则变化**，不补造数据与用户访谈。
