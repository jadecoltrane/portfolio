**10/22 本人给的两个原因,查完一个成立一个不成立:**

- 「自己说的部分增多了」——**配比确实变了**(自己说从 3 张涨到 8 张,占比 15% → 44%),

  `tp`→`to`(纯手滑)、`looks`→`look`(词形)。另外三张填空错的是真不会
  (`like`→`happy`、`crops`→`crossed`、`request`→`requirement`)。
  这两张如果算记得,当天是 11/18 = 61%。

### 🔎 由 10/22 带出的一个设计发现(**先记下,不许现在改**)

「填一个词」用**打字准确度**代理口语能力,而这个产品的第一条主张是「练的是说出口,不是答对」。
`tp` 这种手滑被计进复习结果,**这个题型在用自己产品反对的标准判分**——和 10/18
「题面把答案写进去」是同一类错误:判定没在判它声称要判的东西。

可选的修法(**10/23 收完数据之后再动,现在改会毁掉同口径窗口**):
编辑距离为 1 的纯拼写误差直接算「记得」,或在结果里单开一档「说法记得但拼错」。
