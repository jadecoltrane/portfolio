# 出题梯度 · 可直接贴进每日生成指令

2026-10-24 拟。起因:严口径五天里「填一个词」76 张对 49(64%),「自己说」22 张对 8(36%),
中间是空的。

## 为什么会有这个坎

填空和自己说之间,不是缺一级,是**四件事同时放开**:

| | 填一个词 | 自己说 |
|---|---|---|
| 句子 | 给好的 | 自己造 |
| 用哪个表达 | 空格位置就指明了 | 自己选 |
| 语序 / 时态 / 介词 | 不用管 | 全要管 |
| 产出量 | 一个词 | 一整句 |

## 四级梯度

| 级 | `stage` | 题面给什么 | 要产出什么 | 谁判 |
|---|---|---|---|---|
| 1 | `gap` | 整句,缺一个词 | 那个词 | 机器(编辑距离) |
| 2 | `cue` | 情境 + 首字母串 | 整个表达 | 机器(编辑距离) |
| 3 | `use`(带候选) | 情境 + 2–3 个候选表达 | 挑一个,造一整句 | AI |
| 4 | `use` | 只有情境 | 自己选表达,造一整句 | AI |

第 2 级不是新功能:页面里一直有(`cue` 的提示语、「情景回应」标签、首字母渲染、
自动判分候选词都在线上版本里),只是 10/18 之后生成指令不再出这种题了。

## ⚠️ 两个实现约束(2026-10-24 查过线上页面代码)

1. **自动判分只认 `cue` 和 `gap`。**页面里写死的是
   `const typed = (k.stage==="cue" || k.stage==="gap")`,别的 stage 走不到自动判这条路。
2. **第 3 级不要用 `stage: "match"`。**match 走的是文本框那条路:AI 会判一次并把结果写进去,
   但界面随后仍然显示「忘了 / 模糊 / 记得」三个按钮,一按就把 AI 的结论覆盖掉——
   **等于退回自己判分**,正是 10/18 改掉的那件事。第 3 级用 `stage: "use"`,把候选写进题面。

## 字段写法

**第 1 级 `gap`**(现状,不变)。`answer` 写成 `目标词 (完整说法)`,自动判只取括号前那部分。

```json
{ "stage": "gap",
  "prompt": "Lena says, \"The data won't be ready until Thursday.\" You reply: \"Okay, let's touch ____ on Friday.\"",
  "answer": "base (touch base on Friday)",
  "chunk":  "touch base (on/next week)" }
```

**第 2 级 `cue`**。`answer` 写**整个表达本身**,页面会自动把它渲染成首字母串
(`whenever works for you` → `w________ w____ f__ y__`)。题面只给情境,**不要出现这个表达**。

```json
{ "stage": "cue",
  "prompt": "Priya asks whether you want the call in the morning or the afternoon. You are flexible; let her choose.",
  "answer": "whenever works for you",
  "chunk":  "whenever works for you" }
```

**第 3 级 `use` + 候选**。候选写在题面方括号里,**三个全是地道说法**,只是贴合度不同。

```json
{ "stage": "use",
  "prompt": "Mia asks who knows the voice system best. You want to bring Anna into the thread. [loop (someone) in · touch base (on/next week) · I'd be happy to…] →",
  "answer": "Good question. Let me loop Anna in — she knows the voice system best.",
  "chunk":  "loop (someone) in" }
```

**第 3 级的变体「换个说法」**(推荐优先做这个)。素材用她自己前几天说过的原话。

```json
{ "stage": "use",
  "prompt": "10/22 你是这么说的:\"I'll loop you in the chat.\" 同一个意思,用今天要复习的表达重说一遍。→",
  "answer": "I'll loop Anna in on the chat.",
  "chunk":  "loop (someone) in" }
```

**第 4 级 `use`**(现状,不变):题面只有情境,不带 `(use: …)`,不带候选。

## 出题规则(这几句贴进生成指令)

1. 每张复习卡按它的间隔层级选 stage:第一次复习出 `gap`,第二次出 `cue`,
   第三次出带候选的 `use`,第四次起出不带候选的 `use`。降级的卡退回上一级,不要直接退到 `gap`。
2. **题面永远不许出现目标表达本身。**第 3 级给的是一组候选,不是点名;
   第 2 级给的是首字母,不是答案。(2026-10-18 的教训:`(use: 要用的表达)` 把答案印在了题上。)
3. **候选项必须全是地道说法。**考的是「哪个更合适」,不是「哪个对」——
   编造不地道的干扰项违反决策 02「绝不展示错误的英文」,当初的三选一就是这么被否掉的。
4. 同一个表达每次复习换新场景,不要复用上一次的题面(决策 06)。
5. 一天之内四级都可以出现,但同一个表达当天只出一级。

## 加的时候

- **一次只加一级。**先把第 2 级放回来(零开发量,改生成指令就行),跑几天再上第 3 级。
  一次加两级,又会变成 10/18 那种「四处一起改,说不清是哪处起的作用」。
- **在这份文件里记一笔是哪天加的。**不然之后的数字跟 10/19–10/23 那五天不可比。
- 加完要看的**不是记得率**,是三级之间的落差有没有变平(现在 64% → 空 → 36%),
  以及每天真正记住的个数。
