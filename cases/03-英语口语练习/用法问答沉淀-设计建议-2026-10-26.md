# 把「我问过的英语问题」变成能复习的东西

2026-10-26。素材是昨晚到今天你问的那一批问题。

---

## 一、先筛:你问的问题其实是三类,只有一类该进系统

| 类型 | 例子 | 该怎么办 |
|---|---|---|
| **A 用法对比** | `I'd` / `I'm going to` / `I'll`;`that` vs `which` | **进系统**,下面都在说这类 |
| B 看不懂题 | 「Arabic text in the new build 是啥意思」「搬家那张是啥意思」 | **不进**。这是出题错误,已经由「情境必须自己能看懂」那条规则堵掉了 |
| C 思维方式大问题 | 「外国人说一个句子之前是怎么想的」 | **不进**。答案是一篇文章,不是一张卡。真要留,存进你的记忆库,不是学习页 |

**不筛会出事**:B 类进了系统,等于把出题的错误存成了学习内容;
C 类进了系统,会变成一堆背不动的长文。

---

## 二、为什么不能塞进现在的表达库

表达库的单位是**一个表达**(一句能说出口的话),四级梯度练的是「把它取回来并说出来」。

用法对比的单位是**一组相互排斥的选项**,练的是「在这个场合该用哪一个」。

> 对 `I'd / I'm going to / I'll` 做「换个说法」是没有意义的——
> 它们本来就不是同一个意思,互换就说错了。

**所以要另起一张表,不是在原表里多加几行。**

## 三、一行该存什么

| 字段 | 内容 | 例(你今天问的那个) |
|---|---|---|
| 对比组 | 2–3 个成员 | `I'd do` / `I'm going to do` / `I'll do` |
| **判别标准** | 一句话说清怎么选 | 假设 / 已经计划好的 / 当场决定 |
| **你的场合** ★ | 落到你真实会遇到的情境 | 面试里讲过去的项目、讲「回头看会怎么改」→ `I'd`;讲这周真实的安排 → `I'm going to` |
| 每个成员一个例句 | 短 | `I'd add a pause state.` / `I'm going to send the deck tonight.` / `Sure, I'll send it now.` |
| 来源 | 哪天、从哪张卡问出来的 | 10/26,k? 的批改 |
| 复习次数 / 下次复习 | 同表达库 | |

**★「你的场合」是最值钱的一行,别省。**
「I'd 表假设」是课本;「面试讲过去的项目用 I'd」是你明天真用得上的。
你截图里那段话最后一句就是这个,写得很好。

## 四、怎么考

**主力:产出题,不是选择题。**给情境,她自己写,AI 判**用的形式对不对**(不是判用没用某个表达):

> In an interview, Hannah asks what you'd change about the parking screen.
> You have no plan to actually do it. →
>
> 判定:用了假设形式(I'd / I would)= 对;用 `I'm going to` = 形式不对,
> 因为你并没有这个安排。

这样复用的还是现成的 `use` + AI 判定,只是判的东西换了。

**偶尔:三选一对比卡。**只在她连区别都说不清的时候用。

> **这里的三选一是合法的,跟表达卡不一样。**
> 决策 08 否掉三选一,理由是「选项都成立」;候选题昨天被撤,也是因为
> `I'm down` 跟目标一样地道一样贴合。
> 而用法对比**天生只有一个成立**——这正是它要教的东西。
> 也不违反决策 02:`I'm going to add a pause state.` 是地道英语,
> 只是在这个场合说错了意思。展示的不是错英文,是对英文用错场合。

答完一定要把**完整对比表**再展示一次(就是你截图里那张三行表)。纠正才是正文。

## 五、复习:不按四级出,三步,而且第三步不是卡

### 为什么四级不适用

四级撤的是**「把目标表达取回来」的支撑**。而语法对比根本不需要取回——
`I'd`、`I'm going to`、`I'll` 你随口都说得出。
**难的不是取,是选。**取不回来和选不对,是两种不同的失败,
梯度是为前者设计的,套到后者身上没有意义。

所以换一条难度轴:**意图给得有多明白**。

### 三步

| 第几次 | 什么时候 | 出什么 | 支撑 |
|---|---|---|---|
| 1 | +2 天 | 判别题:情境把意图挑明,提示点出要用哪一类形式 | 意图 + 形式类别 |
| 2 | +10 天 | 产出题:意图藏在情境里,提示不提形式 | 只有意图,要自己读出来 |
| 3 | +30 天 | **不出卡**,改成在批改里查 | 无 |

**第 1 次 · 判别题**(意图挑明)

> In an interview, Hannah asks what you'd change about the parking screen now.
> You have no plan to actually do it — you're only saying what you would do. →
> hint: `Use the form for something hypothetical.`
> 判定:`I'd` / `I would` = 对;`I'm going to` / `I'll` = 形式不对,当场展开完整对比表。

**第 2 次 · 产出题**(意图要自己读出来)

> An interviewer asks about a project that shipped a year ago.
> You notice a flaw now, but nobody is going to change it. Answer the question. →
> hint: 只说「先回答再解释」之类,**不提形式**。

> ⚠️ **出这一级有个坑:题面不能含有正在考的那个形式。**
> 想说明「这是假设」,最顺手的写法就是 `what you would do`——
> 那等于把答案印在题上。得绕开,比如用 `nobody is going to change it` 把假设立起来。
> 这跟表达卡那条「题面不许出现目标表达及其关键词」是同一类规则。

**第 3 次 · 不出卡,在批改里查**

一条用法真学会了,标志是**它不再需要被考**——在她自由产出时自动用对。
所以第 3 次不出题,改成查:这三十天里,她的接着聊 / 语音里有没有自然用对过这个形式?

- 用对过 → 进已掌握
- 用错过 → 退回第 1 步
- 根本没用到 → 再出一张第 2 步的卡,顺延

> **实现要点:**days 文档七天就删了,查不了三十天的历史。
> 所以要**当场记**:批改每天本来就在读她的产出,看到她用对了某个在表里的形式,
> 就给那一行盖个戳 `最后一次正确使用: 11/02`。第 3 次只要读这个字段,不用翻历史。

**这一步顺带补上了你系统里最缺的东西:结果指标。**
「在没人提醒的情况下用对了」是真的学会,比任何记得率都硬。

### 答错了怎么退

第 1 次就答错 → 说明连区别都还没拎清。
下次出**三选一对比卡**(前面说过,这里的三选一是合法的),答完展开完整对比表。
拎清了再回到第 1 步。

### 量

- **每天最多 1 张**,放在 20 张上限之外
- 和表达卡混在一起出,不另开一步
- 用法是规律不是词汇,想通了就比较粘,过度操练会挤掉你本来就不够的时间

## 六、怎么攒进去

你的提示词里 FOLLOW-UPS 已经有一条
「Questions about … why a chunk is said that way → 用中文讲」。
在后面接一句就行:

> 如果这个问题是一组用法对比(两三个形式之间选哪个),
> 除了当场解释,再往「用法」表追加一行:对比组、判别标准、她的场合、
> 每个成员一个例句、来源、复习次数 0、明天到期。
> **如果这组对比已经在表里,扩充那一行,不要新建。**

最后那句有用:你今天问了两次 `that` / `which`,但那是**两个不同的 that**
(一个修饰名词,一个引出整句话)。好的系统应该认出来第二次是同组的新成员,
而不是当成重复。

## 七、展示

三个地方,各干各的:

1. **当场**——就是你截图那样一张三行表(说法 / 什么时候用 / 例子)。
   这个已经够好,不用改。最后再加一句「你的场合」。
2. **复习时**——情境题,答完展开完整对比表。
3. **能翻阅**——所有行攒成一份「我问过的用法」,按对比组排。
   这份清单本身就是复习材料:面试前扫一遍比做题快。

## 七点五、这张表还能收什么

**判据一句话:这件事能不能写成「两三个我都说得出口的形式,场合不同选不同」?**

- 能 → 进这张表
- 只有一个说法 → 那是表达卡,不是用法
- 答案得写成一篇文章 → 进记忆库,不进学习页
- 三个说法互换只是风格变化、意思不变 → 也不进;那是表达卡的「换个说法」。
  **分界线:互换之后会不会说错意思?** 会 → 用法;不会 → 表达

按这个判据,下面这些都合格,而且不限于课本意义上的「语法」:

| 组 | 例 | 为什么对她值钱 |
|---|---|---|
| **情态动词的强度** | `can` / `could` / `might` / `should` / `have to` | 同一个意思,强度不同,决定听起来是建议还是命令。会议和面试里直接影响别人对她的判断 |
| **礼貌与直接的等级** | `Can you…` / `Could you…` / `Would you mind…` / `I was wondering if…` | 严格说是语域不是语法,但形状完全一样。[推论]语域用错的代价比语法错大——语法错听起来是外国人,语域错听起来是态度问题 |
| **冠词与单复数** | 讲研究结论时用 `the user` / `a user` / `users` | [事实,未联网核查]母语里没有冠词的人,这一类错误最稳定、最难自己发现 |
| **时态与体** | `did` / `have done`(讲过去的项目);`was doing` / `did`(讲背景还是讲事件) | 面试全程在讲过去的项目,这组每天都要用 |
| **介词搭配** | `responsible for` / `in charge of` / `own`;`in` / `at the meeting` | 互斥、靠搭配记,正好是这张表的形状 |
| **可数不可数** | `feedback` / `comments`;`research` / `studies` | 设计工作里天天要说的几个词 |
| **连接词的逻辑** | `so` / `because` / `since`;`but` / `although` | 决定一句话的因果听不听得懂 |
| **语序与信息焦点** | `We shipped it last week` / `Last week we shipped it` | 偏高级,排在后面 |

**最值钱的一类不在上表里:她自己重复犯的那个错。** 批改每天都在读她的产出,
同一个形式错误第二次出现时,就把它立成一行。这一行不是通用清单抄来的,
是她自己的——而通用清单里有大半条目她本来就不会错。

**先种三组就够**:情态动词强度、讲过去项目的时态、冠词。其余等它们自己从批改里冒出来。

### 一行还可以多两个字段

- **`反例`**:她当时写错的那一句,原样留着。防复发比正例更有效——
  正例告诉她对的长什么样,反例告诉她自己会往哪儿偏。
- **`混淆对象`**:她实际会误选成哪一个(不是全部成员,是她那一个)。
  出题时专门挑容易误选那个的场合,比随机出情境有针对性。

## 七点六、不是「选哪个」的语法:加一个 kind 字段,三种练法

上一节的判据会把一大片语法挡在外面——那些没有选择、只有对错的,和那些不是用错、
而是根本不会用的。它们该进同一张表,但**不能用同一种题去考**,因为失败的样子不一样。

一行加一个 `kind` 字段,三种:

| `kind` | 失败长什么样 | 例 | 出什么题 | 判什么 |
|---|---|---|---|---|
| **`choice`** 互斥选择 | 选错了 | `I'd` / `I'm going to` / `I'll` | 情境产出题,意图藏在情境里(第七节已设计) | 形式选得对不对 |
| **`rule`** 单一规则 | 根本没装上,漏掉 | 第三人称 -s;可数名词前必须有限定词;`suggest that he do`;嵌入疑问不倒装 `know what time it is` | **改错题**(给一句含这个错的句子,让她改)或**造句题**(给情境,看产出合不合规) | 有没有违规 |
| **`pattern`** 句型工具 | 想不到用 | `Having tested it with five users, we…`;`It took us two sprints to…`;`What surprised me was…` | **定向重写**:给她自己写过的一句平句,要求用这个结构重写一遍 | 用上了没有 + 自不自然 |

### `rule` 的难度轴不是提示,是「有没有被提醒」

| 第几次 | 出什么 |
|---|---|
| 1 · +2 天 | 改错题,直接点名规则:「这句的动词形式有问题」 |
| 2 · +10 天 | 改错题,不点名:「这句有一处形式问题,找出来」;或造句题,看她自己会不会漏 |
| 3 · +30 天 | 不出卡,在她的自由产出里查(和 `choice` 第三步同一个机制,读 `最后一次正确使用` 那个戳) |

**`rule` 这一类最该交给代码,不该交给 AI 判。** 第三人称 -s、冠词缺失、嵌入疑问倒装,
都能用模式在她的产出里直接扫出来。扫出来的既是判定结果,也是新行的候选来源。

### `pattern` 不进复习队列,改成当天的产出要求

句型当卡考会变成背句型——她能认出来、能填空,但自由说话时照样想不到用。
所以它该**下发成约束**,不该当题考:

> 今天的接着聊里,至少用一次 `Having + 过去分词` 开头的句子。

练的是产出时主动调用。判定也简单:用了就是用了。连续两天自然用上 → 进已掌握。

### 三类的来源不一样,这决定了怎么攒

- **`choice`** 从她的提问来(已设计)
- **`rule`** 从批改里她写错的地方来
- **`pattern`** 从她**写对但写笨**的句子来——意思对、结构原始的那些。
  **这是现在缺的一环:批改只在改错,没在挑「对但笨」。** 加一句就行:
  每天批改时,除了错的,再挑一处「意思对但可以用更成熟的结构说」的地方,
  给出改写版,并把那个结构作为一行 `pattern` 候选。

### 上限仍然焊死

三类共用同一个「每天最多 1 张」,不是各开一个上限。`pattern` 的产出要求不占这一张,
因为它不是卡,是附在接着聊上的一句话。

### 还是不进表的

要讲成一篇文章才清楚的语法体系、发音、拼写。前者进记忆库,后两者不是这张表的事。

## 七点七、第四类:`register` 语气档位

`will not` / `won't`、`I hope it doesn't rain` / `won't rain`、`that day` / `on that day`——
**意思一样,两个都对,差的是听起来郑重还是随口。**

前面那条判据(「互换会不会说错意思?会才算用法」)会把这一类挡在外面,但它也进不了表达库:
表达卡的单位是**一个表达**,而这是**同一个表达的两个档位**。那条判据把界划窄了。
(第七点五的「礼貌与直接的等级」其实就是这一类,只是当时没和「意思不变」那条对上。)

所以它是第四个 `kind`:`register`。

### 一行长什么样

| 字段 | 内容 | 例 |
|---|---|---|
| 档位对 | 日常档 / 郑重档 | `won't` / `will not` |
| 判别标准 | 听起来像什么,**不是**什么时候意思对 | 平常说话用缩写;不缩写是在强调,或在写正式文本 |
| 她的场合 | | 面试口语一律日常档;邮件和文档可以升档 |
| 方向 | **她的偏差是单向的** | 往日常档走。[推论]中式英语教育的典型产物是把书面体当口语说,所以这张表只需要练一个方向 |

### 怎么考:不出「选哪个」,出「给场景判档位」

> 你和同事在茶水间随口聊明天的发布。他问会不会延期。→
>
> 判定:用了 `won't` = 对;`will not` = 档位偏高,当场给出对照。

**一半可以机器判**:扫缩写率、扫句首多余的介词(`On that day,` 这类)。

### 更省的做法:不单独出卡,做成批改里的常驻检查

每天批改时,除了改错,标一处「这句偏正式了,口语里会说成 X」。
这和 `pattern` 的来源是同一个入口的两个方向:**对但笨**(结构原始)和**对但硬**(档位过高)。
批改本来就在逐句读她的产出,加这一条几乎不增加成本。

### 顺带一个真指标:缩写率

`won't` / `will not`、`I'm` / `I am`、`it's` / `it is`——这几组在她产出里的缩写比例,
机器可以直接统计。**它是语气档位的代理指标,而且是结果指标不是过程指标**:
不靠她记得什么,只看她自由说话时实际说成什么样。和第五节第 3 步那个
`最后一次正确使用` 的戳一样,都属于「不提醒的情况下做对了」这一类证据。

## 八、代价,先说清楚

这会在表达卡、情景对话、开口练之外,**再加一件每天要做的事**。
你的时间本来就紧,被挤掉的一直是开口练(八天里只做了 3 天)。

所以**上限要焊死:每天 1 张,只收 A 类问题**。
真要在「多一张用法卡」和「今天的开口练」之间选,选开口练。
