## P4｜复盘：二元 → 四级（整页，Hero）

**左右并置图 3 与图 4**，两张图同宽同视觉语言，就是为这一页画的。

| 层 | 内容 |
|---|---|
| L1 | **二元分类的问题不是分得不对，是分辨率不够** |
| L2 | 它只回答"停不停"，不回答"让多少、怎么让、之后怎么回来"——而真实系统里的中间态，恰恰全靠这三个问题定义 |
| L3 | 左：图 3 原始二元分类（标题已写「当年交付版本」，不再另加角标）<br>右：图 4 四级决策树（角标：复盘重建，非当年版本）<br>中间夹三行矛盾证据 |

三行矛盾证据（全部出自原件自身，可逐条翻原文核对）：

| 原始规范怎么归类 | 同一份文档里的实际行为 |
|---|---|
| 拖地图 → 不打断 | 导航桌面页：挂件**半透明不可操作** |
| 节日结束 → 隐含终止 | 壁纸桌面页：**先出提醒通知，再渐隐** |
| 语音唤醒 → 不打断 | 语音 GUI 会遮挡挂件区域 |

🔴 **图 4 的「复盘重建」角标绝不能省。**这一页的说服力全部来自诚实——一旦让人误以为四级模型是当年产出，案例的价值反而归零。图 3 那侧标题已写明「当年交付版本」，不需要再加角标（加了反而啰嗦）。

## P5｜交互稿：规则长什么样

**全案唯一的"设计输出"页。**视觉素材非本人产出，所以这页放的是交互稿，不是视觉大图。

| 层 | 内容 |
|---|---|
| L1 | **挂件放在哪、热区多大、什么时候半透明** |
| L2 | 四张脱敏线框标注稿：联屏落位 / 热区跟随 / **弱化态** / 动效边界 |
| L3 | 图 5，四格；页脚归属说明：底图脱敏重绘，标注层为本人定义 |

🔴 **第 3 格「弱化态」是这一页的理由**：挂件半透明、不可操作——既没有停止，也没有照常播放。它在原始规范里被归进「不打断」，但它显然不是。**这张图是 P4 论点的实证**，排版时不要缩小、不要挪到角落。

⚠️ 归属：底图为线框重绘，**不含产品既有界面与节日视觉素材**。标注层（挂件落位、热区、状态变化、动效边界）已确认为本人定义。

## P6｜结果与反思

| 层 | 内容 |
|---|---|
| L1 | **一套系统行为，覆盖 6 个节日** |
| L2 | 春节 · 圣诞 · 中秋 · 儿童节 · 元旦 · 情人节；规范面向这 6 个节日的彩蛋规划编写，新节日只需挑选事件组合 |
| L3 | 一行小字带过：实际落地情况不掌握，只陈述覆盖范围；视觉动效与 3D 资产非本人产出 |

🔴 **只说覆盖范围，不说上线结果。**6 个节日是规范面向的规划范围；实际是否沿用无从佐证，写成「沿用」就越界了。

⚠️ **这一页不要堆免责声明。**产出边界一行小字即可——大段"这个不是我做的、那个也不是我做的"会让整页读起来像在道歉。归属该交代的地方在 P1 和各图页脚，已经交代过了。

收在反思：

> 一套规则能跑起来，不代表它描述准确了自己。当年那张二元表在每个节日里都工作正常，因为具体行为是我逐个桌面写死的——**分类的粗糙被实现的细致掩盖了。**
