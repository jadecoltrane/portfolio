# 案例⑤ 某新能源品牌车机节日彩蛋

**定位**：方法型短案例，证明我能在情绪体验中定义稳定的系统规则。角色严格限定为**前期规划**：竞品研究、系统边界和交互规范，不把后续视觉动效或量产结果算作个人产出。

**目标篇幅**：PDF 5 页（2026-08-27 拍板）。页面级分镜见 [分镜.md](分镜.md)。

**Hero Artifact**：四级状态仲裁模型（继续／弱化／暂停／终止）。给整页。
**⚠️ 图上必须标注「复盘产物」**——当年交付的是打断／不打断二元规则，四级模型是 2026 复盘时重建的。这条不能省，见 [核对-原始PDF.md](核对-原始PDF.md)。

**金句**："交互设计师的价值是定义系统如何做决定" —— 这句反思是整个案例的灵魂，也与①②④的"系统如何做决定"主线咬合。
