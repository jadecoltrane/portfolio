# 案例② 车载语音助手 → LLM 驱动座舱 Agent 重设计(主力案例)

**定位**:整本作品集的核心证据——证明我能设计"LLM 时代的交互",而不只是画界面。目标读者:大模型公司 + 车企 AI 座舱团队的面试官。

## 选题

挑一个公认体验差的车载语音助手做重设计(选型待定:选自己开过/坐过、能实际录屏取证的)。

## 必须覆盖的五个 AI 交互设计命题

(这五个是 2026-07-07 定的骨架,每个都要有明确的设计产出,不能只是提一嘴)

1. **不确定性表达**:模型不确定时 UI 怎么表现?置信度低时如何降级为确认式交互?
2. **流式响应**:token 逐字吐出时,驾驶场景下的呈现节奏(何时语音播报、何时屏显、何时打断)
3. **Agent 授权边界**:哪些操作 Agent 可以直接执行(调温度)、哪些必须二次确认(导航改道、付款)?边界怎么让用户可感知、可调整?
4. **多模态 + 驾驶注意力安全**:语音/屏显/HUD 的信息分配原则,遵守驾驶分心规范(可引用 NHTSA 分心指南)
5. **失败降级**:网络断、模型幻觉、听错意图时的兜底路径——失败体验是 AI 产品的第一体验

## 可跑 Demo
