# 座舱 Agent 设计原则自检表(案例③遗产,并入案例②附录,1 页)

> 用法:每个界面/流程定稿前过一遍。10 条,每条一个自检问句——答不上来就是设计没做完。

| # | 原则 | 自检问句 |
|---|------|---------|
| 1 | 动作可见 | Agent 刚做的每个动作,用户闭着眼能被告知、睁开眼能看到吗? |
| 2 | 状态有真相之源 | 语音说完就消失了,当前状态在哪个常驻界面能一眼读到? |
| 3 | 撤销快于对话 | 纠错路径比"重新说一遍"更快吗?(一键撤销 vs 再来一轮) |
| 4 | 不确定就换形态 | 模型没把握时,是掩饰成功还是转为确认式?用户能感知到系统的把握程度吗? |
| 5 | 授权按代价分级 | 这个操作错了的代价是什么?分级是按代价定的,还是按技术方便定的? |
| 6 | 底线不可让渡 | 涉钱、不可逆、行车安全的操作,存在任何绕过强确认的路径吗? |
| 7 | 瞥视完整性 | 驾驶中任一时刻瞥一眼屏幕(<2s),看到的是完整可读的信息还是滚动中的半句话? |
| 8 | 等待可解释 | Agent 在"想"的时候,用户知道它在干什么吗?(行为说明 vs 抽象转圈) |
| 9 | 失败有出口 | 每种失败(断网/听错/执行失败)之后,用户的下一步是什么?存在死胡同吗? |
| 10 | 手动永远在 | 任何时刻,用户能在一步之内收回控制权、回到手动操作吗? |

**一句话版**:可见、可撤销、可授权、可瞥视、可退出。

> 溯源:原计划的案例③(AI 信任访谈研究)于 2026-07-10 取消,其启发式精华收敛为本表。条目 1-3 对应信任的建立(行为透明),4-6 对应信任的校准(能力诚实),7-10 对应信任的兜底(控制权保留)。
