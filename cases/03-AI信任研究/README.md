# 案例③ AI 信任机制访谈研究(HCI 研究型小案例)

**定位**:发挥 HCI 硕士的差异化——国内 UX 候选人里能正经做定性研究的少。小而精,10 页以内。

## 研究问题(草案,待收敛)

用户在什么条件下愿意把决策权交给车内 AI?信任如何建立、如何一次性崩塌?

## 方法

- 半结构化访谈 5-8 人(有智能座舱使用经验的车主优先)
- 提纲围绕:信任建立的瞬间 / 收回授权的瞬间 / 对"AI 犯错"的容忍边界
- 编码分析(主题分析法),产出 3-5 条设计启示

## 与案例②的联动

研究结论直接反哺案例②的"Agent 授权边界"设计——让作品集形成"研究 → 设计"的完整叙事闭环,这是整本作品集的结构亮点。
