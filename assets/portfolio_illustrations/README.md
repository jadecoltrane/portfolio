## 重建命令

确保配图 JPG 全部上传，并按仓库既有说明配置 Python 依赖、`PORTFOLIO_FONT_DIR` 的 Noto Sans SC 静态字体后运行：

```bash
python3 tools/build_illustrated.py --variant both --output-dir dist
```

预期文件：

- `dist/car-ux-illustrated.pdf`：46 页
- `dist/product-ux-illustrated.pdf`：34 页

脚本遇到缺失插图**直接终止**，不会无声导出假装完整的作品集。提交二进制文件后才可以宣布 GitHub 的整合版完成同步。
