## 水印

电脑端截图原来都带着「日期 + 真名」的平铺水印。先确认过**不是页面自己画的**——
页面源码里没有 watermark / 水印 / 真名 / rotate(-45 任何一条,是电脑上的截图软件加的。

`去水印.py` 是处理脚本,仓库里这四张都已经跑过了(原始带水印的版本没有留档)。
做法:用 MaxFilter 估出局部背景,把比背景暗 35 以内、且本身亮度 >170 的像素判为淡色叠加;
水印是旋转的字,笔画不会形成长的横平竖直走向,所以**凡是落在 ≥30px 横直线段上的像素一律保留**
——界面上那些 1px 的气泡描边、分隔线、虚线框才不会被一起吃掉。

**残留**(放大到 200% 以上才看得见,正常尺寸看不出):

- `desktop-对话下半` 里「卡住了?看提示」和「发送」两个按钮的圆角描边,左右两头的弧没保住,看起来像下划线
- 另外三张各有两三处 1px 的竖向小刺,是恰好形成长直线段的水印笔画

要完全干净,用系统截图重拍一次就行(macOS ⇧⌘4 / Windows Win+⇧+S)。
