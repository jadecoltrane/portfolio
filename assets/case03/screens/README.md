## 电脑端

`desktop-082d2ce9.jpg` —— 10/20 电脑端主界面。页面 `.wrap` 是 `max-width:820px`,
并有一条 `@media (min-width:760px)` 把 `.step` 改成 `flex:1 1 0`,所以步骤条在电脑上摊成一行,
六步整条都在;手机端是横向滚动的,只露得出三个半。**主界面这一张只能用电脑端。**

这张目前带着「日期 + 真名」的平铺水印,作品集里不能直接用,待换一张不带水印的。

批改卡不受影响:`.fixCard` / `.fixRow` / `.cmp` 在那条断点里都没有被改写,电脑端仍然是上下竖排。
