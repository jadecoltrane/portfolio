# 作品集工作区 — 智能座舱 HMI 交互设计师

> **目标岗位**：座舱 HMI 交互设计师（正编）
> **目标城市**：杭州优先，上海同投
> **雇主优先级**：Tier1 / 外资在华研发中心 > 吉利系正编 > 二线主机厂
> **内容结构**：双主力 + 两个短案例，整本 34–39 页（加可选案例⑥为 37–43）

## 定位

四个案例共享一条主线：**我做的是系统级规则设计，不是页面设计。**
案例①解决控制中心「面板内」的规则，案例②解决「窗口层」的规则，两者同源互证；案例④证明我能在外部平台规范下完成合规落地，案例⑤证明我能在情绪体验里定义稳定的系统边界。

## 为什么案例④是王牌

国内做过出海合规、拿过 GAS/AAOS 认证、懂 RTL 与右舵适配的交互设计师很少。这段经历在国内主机厂内部不值钱，**在 Tier1 和外资在华研发中心是硬通货**——他们做的正是全球车型。因此案例④从原计划的 4–5 页扩到 6–7 页，作为区别于其他候选人的核心筹码。

## 英文版

Tier1 与外资是主要投递对象，**作品集需要一版英文**。已有双语文档基础，正文定稿后统一翻译，不单独维护两套内容。

## 排期（在职投递，不裸辞）

- **第 1–3 周**：案例② 素材确认 + 正文草稿；案例④ 扩写到 6–7 页
- **第 4–5 周**：案例① 事实校准 + 界面脱敏重绘（唯一需要自己画 UI 的地方）
- **第 6 周**：案例⑤ 定稿；排版 + 简历
- **第 7 周**：英文版；开始投递
- **第 8 周起**：面试迭代；有余力再补案例⑥
