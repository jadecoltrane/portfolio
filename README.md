## 案例④ 为什么是经历页而不是案例

国内做过出海合规、拿过 GAS/AAOS 认证、懂 RTL 与右舵适配的交互设计师很少。这段经历在国内主机厂内部不值钱，**在 Tier1 和外资在华研发中心是硬通货**——他们做的正是全球车型。

但 2026-10-19 确认：主框架与开机引导的具体改动由产品侧定义（产品直接给参考图），**没有可写的设计判断**。
硬撑成 6–7 页的 case study，面试追问两层就塌。

**所以改为一页经历页。** 这段经历真正的价值是那几个关键词能通过 Tier1 与外资的简历筛选，
一页就能兑现；设计判断的分量由案例① 承担。**宁可薄，不可撑。**

⚠️ **但「出海」这个筹码目前只靠这一页撑着，而这一页的具体改动还不是她定的。**
2026-10-20 发现一个被低估的补充：**朝拜指南针是为中东市场做的功能**，归属明确是她的
（见 [案例②](cases/02-系统窗口形态/README.md)）。那是功能层面的市场本地化，
补的正是「不只是合规适配，还能为一个具体市场设计功能」——比 GAS 那页更能说明问题。
v1.1 做案例② 时别把它当成顺带一提。
