## 四案例能力链

**① 我在真实量产项目里定义了一套系统规则（面板级 + 控件级）→ ④ 我在外部平台规范下用同一套方法完成差距审查与分级落地 → ⑤ 我用事件仲裁证明交互设计师的价值是定义系统如何做决定。**

三个案例共享“系统如何作出可解释、稳定的决定”这条主线，证据类型互补：①是真实量产交付 + 复盘性规范审查，④是真实方法工作流，⑤是前期系统规划。**三个都是用户本人的真实工作，面试可逐条追问到底。**

> 暂缓的案例②原本承担“把这套规则用在 LLM Agent 上”的延伸论证。它缺席后，AI 方向的表达由 ① 第 6 节承接：**当 Agent 能听懂“我有点冷”，控制中心从操作入口转型为 Agent 行为的可见层。**这一节因此变得更重要，扩写时优先保证。
