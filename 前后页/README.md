## 四页的内容与用意

| 页 | L1（唯一会被先读到的那句） | 这一页在回答什么 |
|---|---|---|
| 封面 | 我做的是系统级规则设计，不是页面设计。 | 全书论点，一句话定位 |
| 关于我 | 我的产出通常不是一屏界面，是一套别人能照着执行的规则。 | 我是谁、做过什么 |
| 目录 | 两个案例，一条主线。 | 这本书怎么组织 |
| 结尾 | 不是我的，我都写了不是我的。 | 收束：这本书的可信度从哪来 |

**结尾那句是认真的**，不是姿态。这本作品集一路在做的就是划归属：
继承来的架构、别人定的顺序、产品给的改动，全部划出去了。
对 Tier1 和外资而言，**一个会划边界的候选人比一个什么都说是自己做的候选人安全得多**——
这一页把这件事挑明，等于把全书最大的特点放在最后一眼。

## 联系方式怎么进 PDF

手机号与邮箱按仓库约定不入库。导出投递版前，在仓库根目录建 `contact.local.txt`
（已加进 `.gitignore`），每行一条：

```
邮箱: 你的邮箱
手机: 你的手机号
```

文件不存在时，结尾页会显示占位文字——**导出投递版前记得建，别把占位发出去**。
